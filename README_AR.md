# آيات - محرر الكابتشن القرآني

![الترخيص](https://img.shields.io/badge/license-MIT-blue.svg)
![البلاتفورم](https://img.shields.io/badge/platform-Android-green.svg)
![اللغة](https://img.shields.io/badge/language-Java-orange.svg)

تطبيق أندرويد حديث لإنشاء كابتشن جميلة للفيديوهات القرآنية مع التعرف التلقائي على الكلام ومطابقة الآيات بالذكاء الاصطناعي.

## المميزات

### 🎯 الوظائف الأساسية
- **التعرف التلقائي على الكلام**: تحويل الصوت إلى نص باستخدام SpeechRecognizer
- **مطابقة القرآن بالذكاء الاصطناعي**: مطابقة ذكية للنص المعترف به مع آيات القرآن
- **محرر الخط الزمني**: أدوات تحرير دقيقة لتوقيت وموقع الكابتشن
- **تخصيص الأنماط**: تنسيق غني للنصوص بخطوط عربية وألوان ورسوم متحركة
- **خيارات التصدير**: تنسيقات تصدير متعددة تشمل SRT وJSON والفيديو مع الكابتشن المدمجة

### 🛠️ أدوات التحرير
- **قص**: ضبط أوقات بداية ونهاية الكابتشن مع تحكم دقيق
- **نقل**: سحب المقاطع لإعادة تموضعها على الخط الزمني
- **تقسيم**: تقسيم المقاطع عند موضع التشغيل الحالي
- **دمج**: دمج المقاطع المتجاورة
- **حذف**: إزالة المقاطع غير المرغوب فيها
- **نمط**: تخصيص الخطوط والألوان والشفافية والموضع
- **موضع**: ضبط دقيق للموضع الرأسي والمحاذاة الأفقية
- **إضافة يدوية**: البحث وإضافة آيات قرآنية محددة

### 🎨 نظام التصميم
- **الجماليات الإسلامية**: ثيم داكن جميل مع لمسات ذهبية
- **دعم RTL**: دعم كامل للغة العربية مع اتجاه النص من اليمين لليسار
- **التصميم المادي 3**: مكونات وواجهات عصرية
- **خط زمني مخصص**: خط زمني مرئي مع التحرير بالسحب والإفلات

### 📱 المميزات التقنية
- **المعالجة المحلية**: جميع المعالجات تتم محلياً، لا حاجة للإنترنت
- **تكامل WorkManager**: المعالجة في الخلفية للعمليات الطويلة
- **قاعدة بيانات Room**: التخزين المحلي للمشاريع والمقاطع
- **Media3 ExoPlayer**: تشغيل حديث للفيديو مع تراكب الكابتشن
- **تطبيع النص العربي**: معالجة متقدمة للمحتوى العربي

## مجموعة التقنيات

- **اللغة**: Java 17
- **Target SDK**: 34 (Android 14)
- **Min SDK**: 28 (Android 9.0)
- **الهيكل**: MVVM مع نمط المستودع
- **قاعدة البيانات**: Room Persistence Library
- **المعالجة في الخلفية**: WorkManager
- **تشغيل الفيديو**: Media3 ExoPlayer
- **إطار واجهة المستخدم**: AndroidX مع التصميم المادي 3
- **معالجة JSON**: Gson
- **الاختبارات**: JUnit

### التثبيت

1. استنساخ المستودع:
```bash
git clone https://github.com/your-username/ayah-caption-editor.git
cd ayah-caption-editor
```

2. فتح المشروع في Android Studio

3. مزامنة المشروع مع ملفات Gradle

4. بناء وتشغيل التطبيق

### البناء

بناء التشغيل:
```bash
./gradlew assembleDebug
```

بناء الإنتاج:
```bash
./gradlew assembleRelease
```

تشغيل الاختبارات:
```bash
./gradlew test
```

## الاستخدام

### إنشاء مشروع جديد
1. إطلاق التطبيق والضغط على "إنشاء فيديو قرآني"
2. اختيار ملف الفيديو باستخدام منتقي الملفات
3. اختيار نسبة العرض إلى الارتفاع (اختياري)
4. الضغط على "استيراد" لبدء المعالجة

### سير عمل المعالجة
1. **استخراج الصوت**: استخراج الصوت من الفيديو
2. **تحويل الكلام إلى نص**: تحويل الكلام إلى نص عربي
3. **مطابقة القرآن**: مطابقة النص مع آيات القرآن
4. **إنشاء الخط الزمني**: إنتاج مقاطع كابتشن قابلة للتحرير

### تحرير الكابتشن
1. اختيار مقطع من الخط الزمني
2. استخدام أدوات شريط الأدوات السفلي:
   - قص: ضبط التوقيت بالشرائح
   - نقل: سحب المقطع إلى موضع جديد
   - نمط: تخصيص المظهر
   - موضع: ضبط تموضع النص
3. معاينة التغييرات في الوقت الفعلي

### التصدير
1. الضغط على زر التصدير في المحرر
2. اختيار جودة وأبعاد التصدير
3. اختيار تنسيق التصدير:
   - **البديل (SRT + JSON)**: متوافق مع معظم مشغلات الفيديو
   - **الدمج (FFmpeg)**: النص مدمج في الفيديو (إذا كان متاحاً)

## الهيكل

### نمط MVVM
- **النموذج**: كيانات Room ونماذج المجال
- **العرض**: الأنشطة والأجزاء والعروض المخصصة
- **عرض النموذج**: إدارة حالة واجهة المستخدم ومنطق الأعمال

### نمط المستودع
- تجريد مصادر البيانات (قاعدة بيانات Room، نظام الملفات)
- توفير واجهة برمجة تطبيقات متسقة لبقية التطبيق
- إدارة التخزين المؤقت والوظائف المحلية

### حالات الاستخدام
- encapsulating منطق الأعمال
- فصل الاهتمامات بين طبقات واجهة المستخدم والبيانات
- تمكين الاختبار والصيانة الأسهل

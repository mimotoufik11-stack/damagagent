# محرر فيديو القرآن الكريم | Quran Video Editor

تطبيق سطح مكتب احترافي لتحرير فيديوهات القرآن الكريم مع دعم كامل للغة العربية وإضافة الكابشنات بشكل احترافي.

<div dir="rtl">

## ✨ المميزات الرئيسية

### 🎬 تحرير احترافي
- **قص ودمج الفيديو** - اقتطاع المقاطع المطلوبة ودمج عدة فيديوهات
- **اقتصاص الفيديو** - تحديد منطقة معينة من الفيديو
- **تغيير الدقة** - دعم جميع الدقات من 480p حتى 4K
- **تعديل النسبة العريضة** - 16:9، 4:3، 1:1، 9:16، 21:9
- **ضبط معدل الإطارات** - 24، 30، 60، 120 FPS

### 📝 كابشنات احترافية
- **استخراج تلقائي** - تحويل الصوت إلى نص باستخدام تقنية Whisper
- **تخصيص كامل** - الخطوط، الألوان، الأحجام، الظلال
- **دعم الخطوط العربية** - Cairo، Amiri Quran، Noto Sans Arabic
- **محاذاة دقيقة** - مزامنة مثالية مع الفيديو
- **تحرير متقدم** - تعديل وقت ظهور واختفاء كل كابشن

### 🎨 التأثيرات البصرية
- **تصحيح الألوان** - السطوع، التباين، التشبع
- **المرشحات** - تطبيق مرشحات مختلفة
- **التأثيرات الانتقالية** - انتقالات سلسة بين المشاهد
- **إضافة الشعارات** - Watermarks بشفافية قابلة للتعديل
- **النصوص والأشكال** - إضافة عناصر مخصصة

### 🔊 معالجة الصوت
- **ضبط مستوى الصوت** - زيادة أو تقليل الصوت
- **دمج مسارات صوتية** - إضافة موسيقى خلفية
- **إزالة الضوضاء** - تحسين جودة الصوت
- **استخراج الصوت** - حفظ الصوت كملف منفصل

### 💾 التصدير والحفظ
- **صيغ متعددة** - MP4، AVI، MKV، MOV، WebM
- **خيارات الضغط** - H.264، H.265، VP9، MPEG-4
- **جودة قابلة للتعديل** - من منخفضة إلى أفضل جودة
- **حفظ المشاريع** - العمل على عدة مشاريع في نفس الوقت
- **تصدير الكابشنات** - حفظ الكابشنات بصيغة SRT

## 🛠️ التقنيات المستخدمة

- **Electron** - بناء تطبيق سطح مكتب متعدد المنصات
- **React 18** - واجهة مستخدم تفاعلية وسريعة
- **Node.js + Express** - Backend قوي ومرن
- **FFmpeg** - معالجة الفيديو والصوت باحترافية
- **Whisper (OpenAI)** - تحويل الصوت إلى نص بدقة عالية
- **Tailwind CSS** - تصميم حديث واحترافي
- **Vite** - بناء سريع ومحسّن

## 📦 التثبيت والتشغيل

### المتطلبات
- Node.js 18 أو أحدث
- npm أو yarn
- FFmpeg (سيتم تحميله تلقائياً)

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone https://github.com/your-repo/quran-video-editor.git
cd quran-video-editor
```

2. **تثبيت المكتبات**
```bash
npm install
```

3. **تحميل FFmpeg**
   - قم بزيارة: https://www.gyan.dev/ffmpeg/builds/
   - حمّل `ffmpeg-release-essentials.zip`
   - استخرج `ffmpeg.exe` و `ffprobe.exe` في المجلد `public/ffmpeg/`

4. **تشغيل التطبيق في وضع التطوير**
```bash
npm run dev
```

5. **بناء التطبيق للإنتاج**
```bash
npm run build
```

سيتم إنشاء ملف EXE في المجلد `dist/`

## 🚀 البناء والتوزيع

### بناء لنظام Windows
```bash
npm run build:electron
```

### بناء لجميع الأنظمة
```bash
npm run build:all
```

### بناء لنظام Android (APK)
```bash
npm run build:android
```

**بديلاً، يمكنك بناء APK تلقائياً عبر GitHub Actions:**
1. ادفع الكود إلى الفرع `main`
2. انتظر إتمام عملية البناء في تبويب Actions
3. قم بتحميل ملف الـ APK من الأرشيف المُنشأ

### الملفات الناتجة
- **Windows**: `QuranVideoEditor-Setup-{version}.exe` (~150-200 MB)
- **macOS**: `QuranVideoEditor-{version}.dmg`
- **Linux**: `QuranVideoEditor-{version}.AppImage`
- **Android**: `app-debug.apk` (متاح عبر GitHub Actions)

## 📖 دليل الاستخدام

### 1. إنشاء مشروع جديد
1. افتح التطبيق
2. اسحب ملف الفيديو أو اضغط "اختر ملف فيديو"
3. انتظر حتى يتم تحميل الفيديو

### 2. إضافة الكابشنات
1. انتقل إلى تبويب "الكابشنات"
2. اضغط "إضافة كابشن" للإضافة يدوياً
3. أو اضغط "استخراج من الصوت" للاستخراج التلقائي
4. خصص الخط والألوان والحجم

### 3. تطبيق الأدوات
1. انتقل إلى تبويب "الأدوات"
2. اختر الأداة المطلوبة (قص، اقتصاص، تغيير دقة، إلخ)
3. اضبط الإعدادات
4. اضغط "تطبيق"

### 4. إضافة التأثيرات
1. انتقل إلى تبويب "التأثيرات"
2. اختر التأثير المطلوب
3. اضبط القيم باستخدام المزلقات
4. اضغط "تطبيق التأثير"

### 5. حفظ وتصدير
1. اضغط "حفظ المشروع" لحفظ عملك
2. اضغط "تصدير الفيديو" عند الانتهاء
3. اختر الصيغة والجودة والإعدادات
4. حدد موقع الحفظ
5. انتظر حتى انتهاء التصدير

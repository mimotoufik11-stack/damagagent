# Arabic Fonts Directory

This directory contains Arabic fonts for the Quran Video Editor.

## Recommended Fonts:

### 1. Amiri Quran
- Beautiful Quranic font with proper Arabic ligatures
- Download: https://fonts.google.com/specimen/Amiri+Quran

### 2. Cairo
- Modern Arabic sans-serif font
- Download: https://fonts.google.com/specimen/Cairo

### 3. Noto Sans Arabic
- Google's comprehensive Arabic font
- Download: https://fonts.google.com/noto/specimen/Noto+Sans+Arabic

### 4. Traditional Arabic
- Classic Arabic font (included with Windows)

## Installation:

1. Download the desired fonts from the links above
2. Extract the `.ttf` or `.otf` files
3. Place them in this directory

## File Structure:
```
public/fonts/
├── AmiriQuran-Regular.ttf
├── Cairo-Bold.ttf
├── Cairo-Regular.ttf
├── NotoSansArabic-Regular.ttf
├── NotoSansArabic-Bold.ttf
└── README.md
```

## Usage:

These fonts will be available for caption styling in the video editor.

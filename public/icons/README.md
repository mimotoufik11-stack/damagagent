# Icons Directory

Place your application icons here:

- `icon.png` - PNG icon for Linux (512x512 recommended)
- `icon.ico` - ICO icon for Windows (256x256 recommended)
- `icon.icns` - ICNS icon for macOS

You can generate these icons from a single source image using tools like:
- https://www.icoconverter.com/
- https://www.img2go.com/convert-to-ico
- https://convertio.co/png-icns/

Recommended sizes for icon.png:
- 512x512 pixels
- 256x256 pixels
- 128x128 pixels
- 64x64 pixels
- 32x32 pixels
- 16x16 pixels
